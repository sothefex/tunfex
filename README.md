# 🌐 Tunfex VPN - Perfis Remotos

Repositório público para distribuição de perfis VPN criptografados.

---

## 📱 Pra que serve?

O app **Tunfex VPN** baixa automaticamente o arquivo `profiles.enc` daqui e carrega seus perfis de conexão.

---

## 🔒 É seguro?

Sim! O arquivo `profiles.enc` é criptografado com AES-256.

- ✅ Público, mas ilegível
- ✅ Só o app com a chave consegue ler
- ✅ Ninguém vê IPs, usuários ou senhas
